About arii/hrm

arii/hrm is an open-source experiment in real-time browser-based fitness tracking. It combines the Web Bluetooth API for hardware connectivity with the Spotify Web Playback SDK for synchronized workout music.

The project serves as a reference implementation for:

  • Next.js 14 App Router
  • Real-time WebSocket State Management
  • Hardware Device Integration in the Browser

Roadmap

We are actively working on:

  • Strava Integration: Securely uploading completed workout summaries (Pending Approval).
  • Advanced Intervals: Custom Tabata/HIIT timers.
