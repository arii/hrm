About the Project

The HRM Fitness Training Dashboard is a web application designed for athletes and fitness enthusiasts to monitor their heart rate in real-time during workouts. The dashboard connects to Bluetooth heart rate monitors and provides a live visualization of heart rate data.

A key feature of this project is its integration with Strava, allowing users to seamlessly sync their workout data, including heart rate, to their personal Strava accounts.

This project prioritizes user privacy. Live heart rate data is streamed for visualization purposes only and is not stored on the server.
