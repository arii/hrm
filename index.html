About the Project

The HRM dashboard allows users to stream their live heart rate from a bluetooth device to a web interface. This data is visualized during the workout but is not stored on the server to ensure user privacy. The dashboard also integrates with the Strava API to sync workout data, including heart rate, to the user's private Strava account.
